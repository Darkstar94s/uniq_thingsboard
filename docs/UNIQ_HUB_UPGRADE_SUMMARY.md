# 🌟 تحديثات منصة UNIQ Smart Home Hub الشاملة (الإصدار المتكامل)

تم الانتهاء بنجاح من تنفيذ كافة المتطلبات الستة بدقة واحترافية عالية، مع ضمان خط رجعة آمن وتحديث السيرفر مباشرة.

---

## 🛡️ 1. خط الرجعة الآمن (Safety Checkpoint & Rollback)
قبل تطبيق أي تعديل، تم عمل **Checkpoint** كامل في مستودع Git ورفعه للـ GitHub:
- **Git Tag:** `v4.3.1.4-checkpoint`
- **Backup Branch:** `backup/before-smarthome-v2`
- **الرجوع لأي لحظة سابقة بضغطة زر عبر السيرفر:**
  ```bash
  git checkout v4.3.1.4-checkpoint
  sudo systemctl restart uniq-gateway
  ```

---

## 🌓 2. النمطين النهاري والليلي (Light & Dark Mode)
- إضافة زر دائري أنيق أعلى شريط العنوان `🌓` للتبديل الفوري بين النمطين.
- **النمط النهاري (Light Mode):** تصميم فائق النقاء مستوحى من لغة تصميم Apple Home و Slate الحديثة، بخلفيات مضيئة وبطاقات بيضاء ناصعة وظلال ناعمة تجعل القراءة مريحة نهاراً.
- **النمط الليلي (Dark Mode):** التصميم الزجاجي الداكن الراقي بالألوان الكونية وعناصر التوهج النيونية.
- يتم حفظ النمط المختار تلقائياً في المتصفح عبر `localStorage` بحيث يفتح النظام دائماً على نمطك المفضل.

---

## 🔄 3. حل مشكلة مزامنة إطفاء المفاتيح (Switch OFF Sync)
- **سبب المشكلة السابق:** كان هناك شرط فحص برمجياً يتجاهل إشارة الـ `OFF` إذا كانت الحالة مسجلة مسبقاً، مما جعل المفتاح عند إطفائه فيزيائياً من الجدار يبقى عالقاً على `ON` في الشاشة.
- **الحل:** تم إزالة العائق وتحديث معالج أحداث Matter بحيث يستقبل إشارة `0` (OFF) فوراً ويحدث الـ State ويرسلها للشاشة وللسحابة دون أي تأخير.

---

## 🌡️ 4. حل مزامنة قراءات حساس الرطوبة والحرارة
- تم تحسين آلية استخراج واستخلاص درجات الحرارة والرطوبة من مجموعات الـ Clusters والـ Datapoints الخام.
- تفعيل معالج `_on_matter_attribute_event` لربط أي تقرير دوري يبثه الحساس وتحديث ذاكرة الكاش اللحظية وبثها فوراً كـ Telemetry للبوابة والسحابة.

---

## ✏️ 5. ميزة تعديل أسماء الحساسات والأجهزة والقنوات
- إضافة زر التعديل `✏️` بجانب اسم كل جهاز، قناة، أو حساس.
- نافذة منبثقة بسيطة تتيح كتابة أي اسم مخصص بالعربية أو الإنجليزية (مثل: "إنارة الصالة الرئيسية"، "حساس حرارة المطبخ").
- يتم حفظ الاسم المخصص محلياً وعلى خادم الهب وتحديث واجهة المستخدم فوراً.

---

## 🗺️ 6. نظام المنزل الذكي المتكامل (Smart Home Multi-View Platform)
تم تحويل الواجهة من صفحة واحدة إلى منصة متعددة الأقسام بشريط تنقل علوي سلس:

1. **📱 الأجهزة المتصلة:**
   - استعراض الأجهزة في شبكة مربعات أنيقة مع فلاتر التصنيف وشريط بحث فوري.
2. **🏠 الغرف والتوزيع:**
   - إنشاء وإدارة غرف المنزل (الصالة، المجلس، المطبخ، غرف النوم، الحديقة).
   - إسناد الأجهزة لكل غرفة ومراقبة بيئتها وأزرار تحكم جماعي (تشغيل الكل / إطفاء الكل للغرفة).
3. **🗺️ المخطط التفاعلي (Interactive 2D Floorplan):**
   - مخطط هندسي معماري افتراضي جاهز.
   - إمكانية **رفع صورة مخطط منزلك الحقيقي (JPG/PNG)** بنقرة واحدة!
   - وضع دبابيس الأجهزة على الخارطة:
     - المفاتيح والإنارات: تتوهج باللون الأخضر/الأصفر عند التشغيل، وبالنقر على الدبوس يتم تشغيل/إطفاء الجهاز فورياً مباشرة من الخريطة!
     - الحساسات: تعرض فقاعة حية فوق الدبوس بالقراءة اللحظية: `🌡️ 24.5°C | 💧 55%`.
4. **⚡ السيناريوهات والأنماط الذكية:**
   - أزرار تشغيل فورية جاهزة بنقرة واحدة:
     - 🌙 **وضع النوم (Good Night):** إطفاء كل الإضاءات فوراً.
     - ☀️ **صباح الخير (Good Morning):** تشغيل إنارات الصالة والمطبخ.
     - 🚪 **مغادرة المنزل (Away):** إطفاء كافة المقابس والأجهزة لتوفير الطاقة.
     - 🎬 **سينما واسترخاء (Cinema Mode):** إضاءة خافتة ومريحة.
     - 💡 **تشغيل شامل (All ON) / ⚡ إطفاء شامل (All OFF)**.
5. **☁️ مزامنة ThingsBoard Cloud:**
   - كشف مباشر لحالة الاتصال بالسحابة (`18.134.221.206`).
   - إمكانية إدخال رمز الوصول **Access Token** الخاص ببوابة ThingsBoard مباشرة من المتصفح وحفظه بنقرة واحدة دون الحاجة لتعديل ملفات السيرفر يدوياً.
   - زر **🔄 مزامنة جميع الأجهزة مع السحابة فوراً**.
